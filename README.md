# 游戏内WebAssembly运行时与沙箱系统

## 项目描述

游戏内WebAssembly运行时与沙箱系统的bug修复项目。核心模块 `runtime/wasm_runtime.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 模块实例化完全没做插件直接跑原生代码
- 沙箱完全没做插件能访问整个文件系统
- 内存管理完全没做插件能越界读写其他模块内存
- 函数调用完全没做插件能调用任意系统函数
- 模块缓存完全没做每次都重新加载模块

## 运行测试

```bash
python -m pytest tests/test_wasm_runtime.py -q
```

修复目标：所有 15 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
